# Gestion de Vente de Voitures (Projet C++ POO)

##  Description du Projet
Ce projet est une application console développée en **C++** selon les principes de la **Programmation Orientée Objet (POO)**. Il permet de gérer un parc automobile en effectuant des opérations de base (CRUD : Ajout, Modification, Suppression, Affichage).

##  Fonctionnalités principales
* **Gestion du catalogue** : Ajout et suppression de véhicules.
* **Modification** : Mise à jour des informations d'une voiture (marque, modèle, année, prix).
* **Affichage** : Consultation claire et structurée du parc automobile.

## Technologies et Outils
* **Langage** : C++ (Standard C++17)
* **Système de build** : CMake
* **Qualité de code** : Clang-Format, Clang-Tidy
* **Gestion de versions** : Git & Gitflow
